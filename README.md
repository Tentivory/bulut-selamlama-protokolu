# Bulut Selamlama Protokolü (BSP-1)

> **Durum:** Üretimde. Test edilmiş. Bilimsel. Uluslararası. Kimse sormadı ama biz yine de yazdık.

Bu depo, gökyüzündeki su buharı kümelerine karşı resmi diplomatik nezaketi standartlaştırmak üzere tasarlanmıştır. Protokol, ISO tarafından henüz kabul edilmemiştir çünkü ISO'ya mail atmadık.

## Neden?

Çünkü bulutlar yüzyıllardır üstümüzden geçiyor, gölge yapıyor, bazen yağmur yağdırıyor ve kimse onlara günaydın demiyor. Bu bir nezaket krizidir. Kriz yönetimi için Python vardır.

## Kurulum

```bash
python3 selamla.py
```

Bağımlılık yoktur. İnternet opsiyoneldir. Bulut zorunludur (pencere yeter).

## Kullanım

```text
$ python3 selamla.py
[BSP-1] Hedef bulut taranıyor...
[BSP-1] Kumülonimbüs mü, cirrus mu, yoksa sadece evin önündeki çamaşır mı karar verilemedi.
[BSP-1] Yine de resmi selam gönderildi.
[BSP-1] Cevap: sessizlik. Bu, protokole göre kabul anlamına gelir.
```

## Bilimsel Dayanak

1. Bulutlar su buharıdır.
2. Su buharı duygu taşımaz.
3. Duygu taşımayan varlıklara selam vermek, modern diplomasiinin zirvesidir.
4. Bu yüzden proje başarılıdır.
